An editorial-grade e-commerce interface designed for the modern luxury consumer. Claire Riche focuses on **asymmetric layouts**, **ethereal typography**, and **cinematic motion sequences** to provide a bespoke digital shopping experience.

---

## ✦ Design Philosophy

The interface is built around a "Modern Noir" aesthetic:
*   **Color Palette:** Deep Onyx (#0d0b09), Antique Cream (#f5f0e8), and Burnished Gold (#c9a96e).
*   **Typography:** The elegant contrast of *Cormorant Garamond* (Serif) and *Tenor Sans* (Sans-Serif).
*   **Motion:** Magnetic scroll reveals and staggered stagger-fade transitions powered by Framer Motion.

## ✦ Core Architecture

### Creative UI Sections
*   **Hero Montage:** A split-screen narrative featuring high-fidelity imagery and gold accents.
*   **Waterfall Collection:** An asymmetric product grid that breaks the traditional e-commerce mold.
*   **Editorial Welcome:** A layered storytelling section with interactive depth.
*   **The Inner Circle:** A minimalist, borderless newsletter invitation for exclusive clientele.

### Technical Stack
*   **Framework:** React 19 (Vite)
*   **Styling:** Tailwind CSS (Utility-first luxury)
*   **Animations:** Framer Motion (Orchestrated scroll-linked animations)
*   **Icons:** React Icons (Desaturated Feather & FontAwesome sets)
